🎧 ListenIn AI

Upload Anything. Learn by Listening.

ListenIn AI is an AI-powered educational platform that helps students and professionals learn smarter by converting PDF documents into interactive audio and text-based learning experiences.

The platform enables users to upload documents, generate AI summaries, listen to AI-generated podcast-style discussions, take quizzes, ask questions using voice, track learning progress, and maintain a personalized learning history.

🚀 Features
🔐 User Authentication (Register & Login)
📄 PDF Upload & Text Extraction
🤖 AI-Powered Summary Generation
🎙 AI Podcast Generation
🎤 Voice-Based Question & Answer System
🧠 AI Quiz Generation
📊 Personalized Learning Analytics
📚 User-Specific Learning History
🗑 History Management (View & Delete)
👤 User Profile Management

🎯 Objective

The goal of ListenIn AI is to make learning more accessible and engaging by allowing users to learn through reading, listening, and interaction while tracking their learning journey.
